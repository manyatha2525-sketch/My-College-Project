# Python Doubt Solver Chatbot

## Project Description

This project is a simple AI Question-Answering Chatbot developed using Python, LangChain, and Google Gemini.

The chatbot is designed to help users understand Python programming concepts by answering their questions in simple language.

## Objective

The objective of this project is to build a simple chatbot using LangChain that accepts a user's question and generates an AI-based answer.

## Technologies Used

- Python
- LangChain
- Google Gemini
- python-dotenv

## Features

- Accepts questions from the user
- Uses Google Gemini to generate answers
- Uses LangChain for connecting the prompt and AI model
- Provides Python explanations in simple language
- Handles empty questions and errors
- Keeps the API key safe using a `.env` file
